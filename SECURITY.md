# Security Policy

## Supported Versions

Security fixes are provided for the latest published version of CyrefJS.

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue.

Instead, report it privately through the GitHub repository security features.

Please include:

- A clear description of the vulnerability.
- Steps to reproduce the issue.
- The potential impact.
- Any relevant proof-of-concept or technical details.

We will review security reports and address confirmed vulnerabilities as appropriate.
