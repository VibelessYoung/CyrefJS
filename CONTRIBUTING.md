# Contributing to CyrefJS

Thanks for contributing to CyrefJS.

## Development

Install dependencies:

```bash
npm install
```

Run the test suite:

```bash
npm run test:run
```

Run type checking:

```bash
npm run typecheck
```

Build the package:

```bash
npm run build
```

Run the full release validation:

```bash
npm run release:check
```

## Pull Requests

- Keep changes focused and minimal.
- Add or update tests for behavior changes.
- Make sure typecheck, tests, and build pass before opening a pull request.
- Use clear commit messages.

## Code Style

Follow the existing project structure and TypeScript conventions. Avoid unrelated changes in the same pull request.
